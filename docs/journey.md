My DevTrack Development Journey

=> Introduction

I wanted to build something useful for students and beginner developers. I decided to make a simple productivity tracker called DevTrack.
The main idea was to create one place where I could manage my coding tasks, track my coding time and write down what I learned.

=> Why I Chose This Project

As a beginner, I sometimes find it difficult to manage my learning tasks and keep track of my daily progress.
That is why I decided to work on DevTrack. I wanted to keep the application simple, clean and easy to use.

=> How I Started

I first planned the basic features of the application. I decided to divide it into four main sections:

1. Overview Dashboard
2. Task Management
3. Coding Session Tracker
4. Learning Journal

After deciding the features, I worked on the basic structure and design of the application.

=> Technologies I Used

I used simple web technologies for this project:

- HTML: To create the structure of the application.
- CSS:To design the pages and make the application responsive.
- JavaScript: To implement the features and handle user interactions.
- LocalStorage: To save tasks, coding sessions and journal entries in the browser.
- GitHub:To manage and upload my project.


=> Features I Implemented

While developing DevTrack, I worked on the following features:

- A dashboard to show coding activity and task statistics.
- A task manager to add, edit, delete and complete tasks.
- A coding timer with start, pause and resume options.
- A learning journal to save daily learning notes.
- Data persistence using browser LocalStorage.

=> My Development Experience

This was one of my first attempts at building a complete web project.

Initially, I was not fully familiar with how HTML, CSS and JavaScript work together. I also had to understand how data can be stored and retrieved using LocalStorage.

While working on the project, I learned that building an application is not only about designing its interface. Every button should perform an action, data should be saved properly and the application should be easy to use.

I also took help from AI tools during development to understand the code, solve problems and move forward. I am still learning how each part works.

=> GitHub and Deployment

After preparing the project files, I created a GitHub repository named DevTrack.

I learned some basic Git commands such as:

- git init
- git add .
- git commit
- git push

I also configured GitHub Pages to publish my project as a live website.

This helped me understand how a project can be shared with other people through GitHub.

=> Challenges I Faced

Some of the main challenges during this project were:

- Understanding how JavaScript handles different user actions.
- Saving data so that it remains available after refreshing the page.
- Understanding how the coding timer works.
- Uploading the project correctly to GitHub.
- Configuring GitHub Pages and fixing the initial deployment issue.

These problems helped me learn more about the development process.

=> What I Learned

Through this project, I got a better understanding of:

- prompt enginering
- Basic frontend development.
- JavaScript functions and DOM manipulation.
- CRUD operations.
- Browser LocalStorage.
- Git and GitHub.
- Basic project documentation.
- Deploying a static website using GitHub Pages.

=> Future Improvements

This is my first version of DevTrack. In the future, I would like to improve it by adding:

- Firebase authentication.
- Cloud database using Firestore.
- Data synchronization across devices.
- More productivity analytics.
- Data export and backup.

=> Final Thoughts

Building DevTrack was a good learning experience for me. I know that this project is not perfect and still has many things that can be improved.

However, it helped me understand how different parts of a web application work together. My main goal was not just to complete a project, but also to learn something practical while building it.

I hope to improve DevTrack as I learn more about software development.
